# Merjohn Pagente: Tailwind CSS site

Responsive profile website built with Tailwind CSS (blueprint design).

- Open `index.html` directly, or host the folder on GitHub Pages. `dist/output.css` is already compiled.
- To edit the design: `npm install`, then `npm run watch` (or `npm run build`).
- Replace the Facebook and email placeholders in the Contact section of `index.html`.
